# 🏢 기업 재무제표

공공데이터포털 금융위원회 기업 재무정보 API (`GetFinaStatInfoService_V2`)를 활용하여 주요 기업의 요약재무제표, 손익계산서, 재무상태표 현황을 실시간으로 조회하고 흑자/적자 신호등으로 시각화하는 반응형 웹 대시보드입니다.

## ✨ 주요 기능
- **경영 실적 신호등 배너**: 영업이익 및 순이익 기반 흑자/적자 신호등(🔵 대규모 흑자 / 🟢 안정적 흑자 / 🔴 영업적자 유의)과 한국어 금액 표기 (조 / 억 / 만 원 단위)
- **Chart.js 가로 막대그래프**: 매출액, 영업이익, 당기순이익, 자산총계, 부채총계, 자본총계를 억 원 단위로 비교하는 인터랙티브 차트
- **상세 재무 카드 그리드**: 계정과목별 한글 환산 금액 및 원문 수치 상세 카드
- **기업 프리셋 및 직접 입력**: 삼성전자, SK하이닉스, 현대자동차 등 주요 기업 원클릭 조회 및 13자리 법인등록번호 직접 검색 지원
- **Vercel 서버리스 아키텍처**: `/api/finance` 서버리스 함수로 공공데이터포털 서비스키 안전 은닉
- **반응형 디자인 & Pretendard 폰트**: 모바일, 태블릿, PC 환경 최적화

## 🛠 기술 스택
- **프론트엔드**: HTML5, CSS3, JavaScript (Vanilla ES6+), Chart.js, Pretendard
- **백엔드**: Vercel Serverless Function (Node.js)
- **데이터 출처**: 공공데이터포털 금융위원회 기업 재무정보 오픈API (`GetFinaStatInfoService_V2`)

## 🚀 로컬 실행 방법
1. `.env.local` 파일에 공공데이터포털 인증키를 입력합니다:
   ```env
   FINANCE_KEY=발급받은_공공데이터포털_인증키
   ```
2. 로컬 서버를 실행합니다:
   ```bash
   node server.js
   ```
3. 브라우저에서 `http://localhost:3000`으로 접속합니다.

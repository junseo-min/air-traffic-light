# 🚦 공기 신호등 (Air Traffic Light)

한국환경공단 에어코리아 실시간 대기오염정보 오픈API를 활용하여 시도별 미세먼지 현황을 '공기 신호등' 형태로 보여주는 반응형 웹 애플리케이션입니다.

## ✨ 주요 기능
- **공기 신호등 메인 배너**: 지역 대표 상태(🔵 좋음 / 🟢 보통 / 🟠 나쁨 / 🔴 매우나쁨)와 평균 PM10 농도, 건강 안내 문구 및 실시간 측정 시각 표시
- **미세먼지 상위 10개 측정소 차트**: Chart.js 기반 가로 막대그래프로 농도가 높은 측정소 순위 및 등급별 색상 시각화
- **측정소별 카드 그리드**: 등급별 은은한 파스텔톤 배경과 테두리가 적용된 측정소별 실시간 상세 카드 (PM10, PM2.5, 측정시각)
- **Vercel 서버리스 아키텍처**: `/api/dust` 서버리스 함수를 통해 공공데이터 API 인증키 은닉 및 보안 강화
- **완전 반응형 디자인**: 모바일, 태블릿, PC 모든 기기에서 최적화된 Pretendard 폰트 UI

## 🛠 기술 스택
- **프론트엔드**: HTML5, CSS3 (Flexbox/Grid), JavaScript (Vanilla ES6+), Chart.js
- **백엔드**: Vercel Serverless Function (Node.js)
- **데이터 출처**: 공공데이터포털 한국환경공단 에어코리아 대기오염정보 오픈API

## 🚀 로컬 실행 방법
1. 저장소를 클론합니다:
   ```bash
   git clone <repository-url>
   cd dust
   ```
2. 루트 디렉토리에 `.env.local` 파일을 생성하고 발급받은 에어코리아 인코딩 인증키를 입력합니다:
   ```env
   AIRKOREA_KEY=여기에_인코딩_인증키_입력
   ```
3. 로컬 서버를 실행합니다:
   ```bash
   node server.js
   ```
4. 브라우저에서 `http://localhost:3000`으로 접속합니다.
